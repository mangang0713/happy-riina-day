## 행사 구분 확인이 필요한 게시물

보류했던 9건은 원문·사진 대조와 사용자 확인을 거쳐 연결했습니다. 현재 수집 목록에 행사 구분 보류 항목은 없습니다.

## 추가로 확인한 연결 근거

- 4월 16일 업로드된 심플리 사진은 4월 10일 촬영, 본문에 260430으로 표기된 EBS 경청 사진은 4월 25일 공개방송 사진임을 사용자가 확인했습니다. 원래 게시일·본문과 정정 근거를 출처 목록에 함께 보존했습니다.
- 3월 13일·27일 개인 사진은 행사명이 명시된 당일 뮤직뱅크 단체사진과 의상·계단·난간 배경을 대조해 연결했습니다. 얼굴 식별을 연결 근거로 사용하지 않았습니다.
- 3월 11일 사진 1의 SHOW CHAMPION 대기실 표지를 확인했습니다. 사용자가 다른 의상의 사진 3·4번을 포함한 전체 사진이 쇼챔피언 자료임을 확인해 4장 모두 연결했습니다.
- 사용자가 3월 15일·22일·29일 개인 사진은 각각 당일 인기가요, 4월 10일 벚꽃 사진은 지금은 라디오시대 공개방송 자료임을 확인했습니다. 같은 날짜 팬사인회·다른 방송으로 복제하지 않았습니다.
- 5월 12일·13일 개인 게시물은 원문 전체에서 당일 두 행사를 함께 언급한 공통 자료임을 확인했습니다.

## 분류 시 제외한 자료

- 김천 등 등록되지 않은 행사와 KFN 위문열차, 홍보용 브이로그 표지는 추가하지 않았습니다.
- 11월 24일 공통 게시물의 멤버별 개인 사진 4장은 단체 탭에 넣지 않았습니다. 리이나 개인 사진은 #리이나 게시물의 2장으로 연결했습니다.
- Instagram·YouTube 수집 및 릴스 임베드는 이 X 사진 점검에 포함하지 않았습니다.

## 검증 결과

- 연결한 이미지 주소 288종은 2026-11-26 로그인 정보 없는 HEAD 요청에서 모두 HTTP 200과 이미지 Content-Type을 확인했습니다.
- 행사 상세·전체 기록·영상통화 일정에서 사진 표시, 확대·이전/다음·닫기를 확인했습니다. 확대창에서 Escape를 누르면 사진만 닫히고 원래 버튼으로 포커스가 돌아옵니다.
- 390×844 모바일 화면에서 행사 상세와 전체 기록의 가로 넘침이 없고, 사진 확대창이 화면 안에 표시되는 것을 확인했습니다. 영상통화의 개인 사진 2장도 표시·확대를 확인했습니다.
- 사진이 없는 2월 21일 일정에는 빈 공식 사진 영역이 표시되지 않았습니다. 검사한 화면에서 새 콘솔 오류가 없었습니다.
- 확대창의 Tab·Shift+Tab이 배경으로 빠지는 문제를 수정하고, 닫기·이전·다음 버튼 안에서 순환하는 것을 확인했습니다.
- 사진 확대 중 브라우저 뒤로가기로 다른 화면에 이동했을 때 미리보기 대화상자가 함께 제거되는 것을 확인했습니다.
- 사용자가 확정한 4월 25일 경청 단체사진 2장, 3월 11일 쇼챔피언 개인 사진 4장, 4월 10일 라디오 공개방송 단체 1장·개인 3장의 실제 화면 표시와 이미지 로딩을 확인했습니다.
- 최종 `npm run build`, `npm run lint`, `git diff --check`가 통과했습니다. 기존 지도 번들 크기와 Supabase 클라이언트 혼합 import 경고는 남아 있습니다.
- 원본 일정 122개와 사진 데이터·감사 목록을 대조해 없는 일정 참조, 원본 게시물 중복, 사진 URL·수량 불일치가 없음을 확인했습니다. 임시 대조 파일은 제거했습니다.
